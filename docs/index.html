What it does

Six modules working together, all inside one sidebar.

Tab Intelligence & Agents

Reads your open tabs and routes chat to specialized agents for coding, research, learning, or career questions.

Quick Actions Toolbar

Select any text on any page to Explain, Summarize, Simplify, Define, or turn it into a quiz — instantly.

Quiz Generator

Turns whatever you're reading into a short AI-generated quiz on its own page — great for studying.

Memory & Personalization

Remembers past interactions via a RAG-style memory store, with a panel to view or forget anything, anytime.

Secure Sign-In

Google sign-in keeps your chats and memory tied to your account, backed by a real MySQL database.

Page Summaries

One click gives you a clean summary of the page you're on, plus smart follow-up questions to ask next.

Install it

Not on the Chrome Web Store yet — here's how to run it locally.

1

Clone the repo

git clone https://github.com/madhwanibhumika24/BrowserMind.git

2

Start the backend

Follow backend/README.md to set up the virtual environment, install dependencies, and run the FastAPI server.

3

Load the extension

Open chrome://extensions, enable Developer mode, click "Load unpacked", and select the frontend folder.

4

Sign in and go

Click the BrowserMind icon on any page, sign in with Google, and start chatting.
